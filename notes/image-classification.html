Run the data demo locally

The scikit-learn and PyTorch pixel-classification notebooks use the GF1 image and label rasters on the course server. Replace username with your account name:

sftp username@femianjc-gpu.csi.miamioh.edu:/srv/courses/cse620b/demo-lulc.ipynb
sftp username@femianjc-gpu.csi.miamioh.edu:/data/cse620b/ch12-data/C-megacities/Image__8bit_NirRGB/GF1_PMS2_E113.7_N30.2_20160614_L1A0001642547-MSS2.tif
sftp username@femianjc-gpu.csi.miamioh.edu:/data/cse620b/ch12-data/C-megacities/label_dense__color/GF1_PMS2_E113.7_N30.2_20160614_L1A0001642547-MSS2_dense.tif

Run Jupyter locally and install the packages required by the notebook in your environment. The DeepGlobe notebook downloads its dataset from Hugging Face on first run.
