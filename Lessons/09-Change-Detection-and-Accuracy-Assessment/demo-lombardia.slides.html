Lombardia: One Patch, Twelve Dates¶

Follow Sentinel-2 patch 1208 in Lombardia3 through 2019: RGB images, differences, spectral distances, paired-pixel correlation, and a trajectory. Open in Colab. Install rasterio in a fresh Colab runtime with %pip install rasterio.

Source: Gallo et al., Sentinel-2 Image Time Series for Crop Mapping, https://www.kaggle.com/datasets/ignazio/sentinel2-crop-mapping (CC0). The author's RGB exporter uses stored channels 3, 2, 1 and scale 0.0001: https://github.com/mattiagatti/sits-crop-segmentation-models/blob/main/misc/export_samples_rgb.py We use the confirmed red channel, not an assumed NIR channel. Nodata is masked; these nine-band chips provide no separate cloud-quality band. These are observations of agricultural appearance, without dated disturbance labels.

Two dates: signed differences and multiband distances¶

March 13 minus March 8. The red difference uses symmetric limits around zero; blue means decrease and red means increase. The two RGB views share a stretch. Magnitude combines all nine stored channels. Spectral angle compares their proportions. These summarize measured differences; interpret causes using imagery.

before, after = images[:2]
common = np.isfinite(before).all(axis=0) & np.isfinite(after).all(axis=0)
red_difference = np.where(common, after[2] - before[2], np.nan)
magnitude = np.where(common, np.linalg.norm(after - before, axis=0), np.nan)
norm_product = np.linalg.norm(before, axis=0) * np.linalg.norm(after, axis=0)
cosine = np.divide((before * after).sum(axis=0), norm_product,
                   out=np.full(common.shape, np.nan), where=common & (norm_product > 0))
angle = np.degrees(np.arccos(np.clip(cosine, -1, 1)))
limit = np.nanmax(np.abs(red_difference))
fig, axes = plt.subplots(1, 3, figsize=(12, 4), layout="constrained")

Paired pixels, trend line, and cross-correlation¶

Each point is one valid location's red value on the two dates. Pearson r, slope, and intercept summarize this patch as one analysis region. The dashed identity line marks equal values. This is the book's regional calculation, repeated on the same patch used for the images and differences above.

first = before[2][common]
second = after[2][common]
correlation = np.corrcoef(first, second)[0, 1]
slope, intercept = np.polyfit(first, second, 1)
line_values = np.linspace(min(first.min(), second.min()), max(first.max(), second.max()), 100)
fig, axis = plt.subplots(figsize=(7, 5), layout="constrained")
axis.scatter(first, second, s=8, alpha=0.3, edgecolors="none", color="#216b86")
axis.plot(line_values, line_values, "--", color="#666666", label="Equal values")
axis.plot(line_values, slope * line_values + intercept, color="#b2182b",
          label=f"y = {slope:.3f}x {intercept:+.3f}")
axis.set(xlabel="March 8 red", ylabel="March 13 red",
         title=f"Lombardia: r = {correlation:.3f}, n = {first.size:,}")
axis.legend()
axis.grid(alpha=0.2)
fig.savefig(output_dir / "lombardia-correlation.png", dpi=150)
print(f"r={correlation:.6f}; slope={slope:.6f}; intercept={intercept:.6f}")

From an image sequence to a trajectory¶

Track the median red value of the marked 12 by 12 pixel window across actual acquisition dates. The same window is used every time. The curve summarizes appearance through the year; RGB images help interpret vegetation, soil, and atmospheric contributions. For this teaching crop, visual RGB inspection excludes April 12, May 12, July 11, October 9, November 8, and December 8 because clouds/haze obscure the window. This manual selection is explicit; a production analysis should use a documented quality mask. Gaps remain visible.
