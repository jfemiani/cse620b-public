Understanding Coordinate Reference Systems (CRS) and Transforms¶

Coordinate Reference Systems (CRS)¶

A Coordinate Reference System (CRS) defines how the two-dimensional, projected map in your raster relates to real places on the earth. In geospatial analysis, it's crucial to know the CRS used by your raster data, as it affects how the data aligns with other datasets. The CRS is often specified using an EPSG code, a standard code that identifies different geographic and projected coordinate systems.

For example:

  • EPSG:4326: This is the code for WGS84, a commonly used geographic coordinate system that uses latitude and longitude.
  • EPSG:32633: This code refers to UTM zone 33N, a projected coordinate system commonly used for mapping in Europe.

Transforms¶

The transform in a raster dataset maps the pixel locations in the raster grid to coordinates in the CRS. The transform is typically an affine transformation, which is a linear mapping method that preserves points, straight lines, and planes. The transform is crucial for aligning raster data with other spatial data.

The affine transformation is represented by a matrix that contains six parameters:

  • A (src.transform[0]): The pixel width (the size of one pixel in the CRS units).
  • B (src.transform[1]): The row rotation (usually 0 for north-up images).
  • C (src.transform[2]): The x-coordinate of the upper-left corner of the image.
  • D (src.transform[3]): The pixel height (typically negative, because the y-coordinate increases downwards).
  • E (src.transform[4]): The column rotation (usually 0 for north-up images).
  • F (src.transform[5]): The y-coordinate of the upper-left corner of the image.

These parameters help translate between pixel coordinates in the raster and real-world coordinates in the CRS.

The affine transformation can be represented mathematically as:

$$ \begin{pmatrix} X \\ Y \end{pmatrix} = \begin{pmatrix} A & B \\ D & E \end{pmatrix} \begin{pmatrix} i \\ j \end{pmatrix} + \begin{pmatrix} C \\ F \end{pmatrix} $$

Where:

  • $X, Y$ are the real-world coordinates.
  • $i, j$ are the pixel coordinates in the raster grid.

Well-Known Text (WKT) for CRS¶

The Well-Known Text (WKT) format is a text markup language for representing coordinate reference systems. It is commonly used to define the spatial reference of datasets in a human-readable format.

For example:

  • The WKT for EPSG:4326 (WGS84) might look like this:
GEOGCS["WGS 84", DATUM["WGS_1984", SPHEROID["WGS 84",6378137,298.257223563, AUTHORITY["EPSG","7030"]], AUTHORITY["EPSG","6326"]], PRIMEM["Greenwich",0, AUTHORITY["EPSG","8901"]], UNIT["degree",0.0174532925199433, AUTHORITY["EPSG","9122"]], AUTHORITY["EPSG","4326"]]
  • The WKT for EPSG:32633 (UTM zone 33N) might look like this:
PROJCS["WGS 84 / UTM zone 33N", GEOGCS["WGS 84", DATUM["WGS_1984", SPHEROID["WGS 84",6378137,298.257223563, AUTHORITY["EPSG","7030"]], AUTHORITY["EPSG","6326"]], PRIMEM["Greenwich",0, AUTHORITY["EPSG","8901"]], UNIT["degree",0.0174532925199433, AUTHORITY["EPSG","9122"]], PROJECTION["Transverse_Mercator"], PARAMETER["latitude_of_origin",0], PARAMETER["central_meridian",15], PARAMETER["scale_factor",0.9996], PARAMETER["false_easting",500000], PARAMETER["false_northing",0], UNIT["metre",1, AUTHORITY["EPSG","9001"]], AUTHORITY["EPSG","32633"]]

Understanding WKT helps in interpreting and managing the spatial reference systems of your geospatial data, ensuring that different datasets align correctly when overlaid.

import numpy as np
import rasterio
import matplotlib.pyplot as plt

# Load the raster data
with rasterio.open('data/o41078a1.tif') as src:
    band_data1 = src.read(1)  # Read the first band

# Function to calculate basic statistics of a raster band
def calculate_statistics(band_data):
    stats = {
        'mean': np.mean(band_data),
        'min': np.min(band_data),
        'max': np.max(band_data),
        'std': np.std(band_data)
    }
    return stats

# Calculate and print statistics for the first raster band
band1_stats = calculate_statistics(band_data1)
print("Statistics for Band 1:")
print(f"  - Mean: {band1_stats['mean']}")
print(f"  - Min: {band1_stats['min']}")
print(f"  - Max: {band1_stats['max']}")
print(f"  - Std Dev: {band1_stats['std']}")

# Apply a simple transformation: Scale the pixel values by a factor of 2
band1_scaled = band_data1 * 2

# Display the scaled raster data
plt.imshow(band1_scaled, cmap='gray')
plt.title('Band 1 - Scaled (x2)')
plt.colorbar()
plt.show()

Best Practices When Using rasterio¶

When working with raster data in Python, rasterio is an essential library that provides a powerful interface for handling geospatial data. Here are some best practices to follow:

Best Practices:¶

  1. Use Context Managers:

    • Always use the with rasterio.open(filepath) as src: pattern when opening files. This ensures that the file is properly closed after your operations, preventing potential issues with file access.

  2. Check Metadata First:

    • Before performing operations on raster data, inspect the metadata. This helps you understand the structure and format of the data, such as the number of bands, dimensions, and CRS.

  3. Leverage NumPy for Data Manipulation:

    • Use NumPy to manipulate the raster data after reading it with rasterio. Operations like statistical analysis and transformations (e.g., scaling pixel values) are efficiently handled using NumPy arrays.

  4. Visualize Your Data:

    • Use visualization tools like matplotlib to inspect your raster data visually. This step is crucial for verifying that your data looks correct after processing.

Example in This Notebook:¶

In the previous cells, we followed these best practices:

  • We used context managers to ensure files were opened and closed properly.
  • We inspected the metadata of the raster files to understand the data we are working with.
  • We performed statistical analysis and a simple transformation using NumPy.
  • We visualized the raster data to confirm our operations produced the expected results.

output_filepath = 'data/scaled_band1.tif'

# Save the scaled raster data to a new file
with rasterio.open(

    'w',
    driver='GTiff',
    height=band1_scaled.shape[0],

    count=1,  # Number of bands
    dtype=band1_scaled.dtype,
    crs=src.crs,
